## 기능 요구사항 분석

### 입력

- [ ]  경주할 n개의 자동차 이름을 입력받는다. (이름은 쉼표(,) 기준으로 구분)
    - [ ]  이름은 5자 이하만 입력 가능하다.
- [ ]  시도할 횟수를 입력받는다.

### 기능

- [ ]  시도 횟수만큼 경주를 실행한다.
    - [ ]  각 자동차마다 전진 여부를 구한다
    - [ ]  출력할 차수별 실행 결과를 저장한다.
- [ ]  우승자를 선정한다.

### 에러

- [ ]  `ERROR` 메시지와 함께 에러 발생
    - [ ]  애플리케이션 종료 (단, `process.exit()`를 호출하여 종료하지 않는다.)
    - [ ]  자동차 이름 입력 오류
        - [ ]  글자 수 제한 (e.g. 입력 값 없음, 6자 이상 입력)
    - [ ]  시도할 회수 입력 오류
        - [ ]  양수가 아닌 경우(e.g. 음수, 0, 소수, string 등)

### 엣지 케이스

- [ ]  우승자가 없는 경우
    - [ ]  안내 메시지와 함께 종료

### 출력

- [ ]  각 자동차의 차수별 실행결과를 모두 출력한다.
    - [ ]  전진한만큼 `-` 의 개수로 표현한다.
- [ ]  우승자를 출력한다.
